📥 How to Install MetaMask:

🦊 Browser Extension (Recommended)
  1. Chrome/Edge: Install from Chrome Web Store
  2. Firefox: Install from Firefox Add-ons
  3. Brave: Install from Chrome Web Store
📱 Mobile App (Alternative)
  1. iOS: Download from App Store
  2. Android: Download from Google Play

🔧 Setup Steps After Installation:

  1. Open MetaMask: Click the MetaMask fox icon in your browser toolbar
  2. Create Account: Choose "Create a new wallet" or "Import an existing wallet"
  3. Set Password: Create a strong password for your wallet
  4. Backup Phrase: Write down your 12-word recovery phrase and store it safely
  5. Verify Backup: Confirm your recovery phrase to complete setup
  6. Connect to DApp: Refresh this page and click "Connect MetaMask"
💡 Testing Tips:
  • Use Testnet: Switch to Sepolia testnet for free testing
  • Get Test ETH: Use Sepolia Faucet for free test tokens
  • Network Switch: Click the network dropdown in MetaMask to change networks

After switching: Get free test ETH from Sepolia Faucet

🔒 Security Reminders:
  • Never share your 12-word recovery phrase with anyone
  • Store backup phrase in a secure, offline location
  • Use strong passwords and enable biometric authentication if available
  • Verify URLs before connecting to any DApp

🔧 Troubleshooting Coinbase Wallet Connection Issues:

🚨 Common Issues & Solutions:
  • Wallet is locked: Click the blue Coinbase Wallet icon and enter your password
  • No accounts found: Create a new wallet or import an existing one in Coinbase Wallet
  • Connection popup not appearing: Check if popups are blocked in your browser settings
  • Connection rejected: Make sure to click "Connect" in the Coinbase Wallet popup
  • Extension not responding: Try refreshing the page or restarting your browser
  • Wrong network: Click the network dropdown in Coinbase Wallet and switch to Ethereum Mainnet or Sepolia testnet
  • Browser permissions: Ensure Coinbase Wallet has permission to access this site
🔧 Step-by-Step Troubleshooting:
  1. Check Extension: Look for the blue Coinbase Wallet icon in your browser toolbar
  2. Verify Login: Click the extension and make sure you're logged in
  3. Clear Cache: Try refreshing this page (Ctrl+F5 or Cmd+Shift+R)
  4. Check Network: Ensure you're connected to Ethereum Mainnet or Sepolia testnet
  5. Try Again: Click "Connect Coinbase Wallet" and approve the connection
  6. Restart Browser: If all else fails, close and reopen your browser
💡 Pro Tips:
  • Mobile Sync: If using mobile, make sure your browser extension is synced with your mobile app
  • Multiple Accounts: If you have multiple accounts, make sure you're using the correct one
  • Testnet First: Try connecting on Sepolia testnet first to test the connection
  • Update Extension: Make sure you have the latest version of Coinbase Wallet
